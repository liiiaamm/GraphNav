    What you're watching

    Dijkstra keeps a priority queue of intersections ordered by their distance from A, always settling the closest one next. The pink spreading across the map is that order, played back. It is guaranteed to find the best route, but it searches in every direction at once, including away from B.

    A* adds a guess of the distance still to go, the straight line to B, to each intersection's priority. The guess never overestimates, so the route is still optimal, but the search leans towards B and settles far fewer intersections.

    The weights

    Distance uses each street's length in metres. Time divides it by the speed limit, or a default by road type when OpenStreetMap has none: 30 km/h on residential streets, 50 on avenues, 100 on the M-30. Slow junctions adds an expected 24 seconds (an 80 % chance of a 30-second wait) at every intersection on a major road.

    That last mode fixes a bug in the original Python version, which looked for traffic signals in the road type of each street. OpenStreetMap stores signals on intersections, not streets, so the penalty never applied and the mode returned the same route as plain time.
